OFFLINE DAoC REMASTERED - BETA v0.1  (November 3, 2026)
=======================================================

Dark Age of Camelot, offline: the OpenDAoC server and the new Godot client, with everything built since
Offline DAoC 0.36c - the remastered world, action combat, housing, mounts, dynamic events, level bands and
scaling, special loot, the modern interface (Options > INTERFACE > STYLE) with the Hero panel, the big map
and the modern bags.

PLAYING
  START OFFLINE DAOC - NEW CLIENT.cmd   the launcher: start the server, then ENTER REALM.
  Your account and password are already filled in (runtime\account.txt).

WHICH WORLD
  The Beta starts in a FRESH WORLD: no characters and no bots, every house lot for sale, the keeps back with
  their first realms. Make your characters, then add bots in the launcher's bot page (10 or 100 per realm,
  level 1 or 50).
  Your world as it was on November 3 (Rian, Lancelot, Skodi, ... and the 410 bots) is included:
  SWITCH WORLD.cmd  swaps between them (the server must be stopped). The world you leave is always kept, so
  switching never loses anything.

PLAYING ON MORE THAN ONE COMPUTER
  See SYNC AND UPDATE - READ ME.txt. Careful: the cloud save in Google Drive ("OfflineDAoC Saves") is still
  your old world. The first time you start PLAY OFFLINE DAOC (SYNCED).cmd on a computer it asks which save
  to use - choose THIS COMPUTER's to put the Beta world in the cloud, or the cloud's to go back to the old one.

WHAT'S LEFT OUT (to keep the download smaller)
  The original game client (only START OFFLINE DAOC.cmd - the old client - needs it), the patch backups,
  logs and caches. The new client builds its shader cache again the first time you play (a slow first minute).

IF SOMETHING GOES WRONG
  Windows may ask to allow the server through the firewall the first time: allow it (private networks).
  If the launcher or the game doesn't start, install the Microsoft Visual C++ Redistributable (x64) and the
  latest graphics driver, then try again.
